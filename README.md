# Робот-Вайбкодер — публичный канал релизов

Домашний AI-ассистент на Raspberry Pi: голос, Telegram, камера, свет,
постоянная память, самообновление.

**Здесь лежат только собранные подписанные релизы.** Исходный код
разрабатывается в приватном репозитории; наружу уезжает срез по тегу.

## Что нужно

| | |
|---|---|
| Плата | **Raspberry Pi 4 или 5**, минимум 2 ГБ ОЗУ (рекомендуется 4 ГБ) |
| Карта | 16 ГБ+ |
| ОС | Raspberry Pi OS **64-bit** (Bookworm/Trixie) |
| Ключи | свои: OpenRouter (мозг) и Telegram-бот. Ничего общего с автором |

**Raspberry Pi Zero (любой) не поддерживается.** Замер: один только мозг с
памятью занимает ~960 МБ, у Zero 2 W всего 512 МБ. Устройство честно откажется
обновляться, а не превратится в кирпич.

## Установка — одна команда

На чистой Raspberry Pi OS (64-bit), в терминале Pi:

```bash
curl -fsSL https://raw.githubusercontent.com/ssheleg/robot-vibecoder/main/install.sh | bash
```

Скрипт сам проверит железо, скачает подписанную сборку, **проверит подпись**
и распакует. Дальше — один раз ввести свои ключи (OpenRouter + Telegram-бот):

```bash
cd ~/rpi-ai-assistant && bash installer/install.sh
```

Не подходит железо (Zero, 32-битная система, мало ОЗУ) — скрипт скажет об
этом сразу и ничего не установит.

### Доверие

Сборки подписаны; публичный ключ автора лежит здесь же (`allowed_signers`),
и устройство проверяет им КАЖДОЕ обновление. Первое доверие — к HTTPS этого
репозитория (trust-on-first-use); дальше ключ живёт локально.

## Обновления

Устройство само проверяет канал `channels/stable.json`, **проверяет подпись**
и обновляется. Артефакт без верной подписи не применяется никогда.

## Приватность

Телеметрии нет. Устройство ничего о себе не сообщает автору проекта: оно
только читает канал. Ваши ключи, разговоры и память остаются у вас.

## Лицензия и гарантии

Проект личный, отдаётся «как есть». У агента широкие права на своей машине
(включая shell) — это осознанный выбор ради автономии; ставьте на выделенное
устройство, а не на рабочий компьютер.
